# Security / Seguridad

To report a security problem with this website, email **comercial@allcleanfloridagroup.com** with the subject "Security". Please do not open a public issue.

Para informar de un problema de seguridad en esta web, escribe a **comercial@allcleanfloridagroup.com** con el asunto "Security". No abras una incidencia pública.

Breach notification to affected people follows section 501.171, Florida Statutes (see the Privacy Policy).
